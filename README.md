# Finance Assistant Backend

This repository implements the backend API for the Finance Assistant project.

Developer requirements
- All public API endpoints must be documented via OpenAPI (FastAPI auto-generated `/openapi.json`).
- Tests must validate generated OpenAPI specs for new/modified endpoints.
- List endpoints must support pagination/filtering/sorting; cursor-based pagination helpers are provided in `app/api/utils/pagination.py`.

See `ROADMAP.md`, `TESTS.md`, and `TODO.md` for project plan and testing guidelines.
